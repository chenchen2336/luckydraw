## 简介

幸运抽奖机是一个**只装在服务器上**的 Fabric 26.3 抽奖模组：右键抽奖方块（默认原版磁石）、手持时钟右键或输入 `/lottery` 打开抽奖界面，从自己的经济账户扣钱，抽到的物品直接进背包。

模组没有新增方块、物品、粒子、音效和界面资源，界面用原版箱子界面绘制，所以**客户端不需要安装本模组**，纯净客户端也能正常玩。

## 内容

- **单抽与十连**：两套独立奖池、各自独立价格，默认单抽 100、十连 900；界面会显示十连比单抽十次省多少。
- **权重概率**：每个奖品配一个权重，界面悬停和 `/lottery pool` 都会显示实际概率。
- **保底**：默认每 50 抽必出稀有奖励（配置里标 `rare` 的奖品），出稀有后计数清零；进度存在 `<世界目录>/lottery/players.json`，重登、重启都不丢。
- **抽奖界面**：6 行 54 格，第一行是单抽奖池预览，第二行是十连奖池预览，另有单抽、十连、保底进度、我的钱包、玩法说明五个按钮；界面里的图标拿不走。
- **粒子与音效**：抽奖时脚下环形火焰与末地烛粒子上升，滴答声越来越密集、音调越来越高；开奖时烟花、图腾、村民粒子爆开并播放升级音效，稀有奖额外播放挑战完成音效并全服公告。
- **三种奖品**：物品（背包满会掉在脚下）、直接发钱（走同一个经济账户）、服务器命令（`%player%` 自动替换成玩家名）。
- **普通玩家不用 OP**：命令类奖品默认以玩家为执行者、临时借用管理员权限执行，`give %player% diamond 1` 这类命令对非管理员玩家也生效；跑不了的命令会自动改用控制台身份再试一次。
- **防重复扣费**：上一轮没开奖时不能再抽；扣费后掉线会自动退款；服务器关闭前会把进行中的抽奖结算或退款。

## 合成与获取

本模组没有新增物品和方块，因此没有合成配方，触发方式如下：

- 右键**磁石**（`minecraft:lodestone`）打开界面；
- 手持**时钟**（`minecraft:clock`）右键打开界面；
- 或直接输入 `/lottery`、`/lottery open`。

触发的方块和物品都能在 `config/luckydraw/lottery.json` 的 `machine.block` / `machine.item` 里改成任意原版方块或物品，写 `""` 即可关掉对应触发方式。

## 安装

1. 把 jar 放进**服务器**的 `mods/` 文件夹（Fabric 26.3，需要 Fabric API）。客户端不用装。
2. 经济模组 Savs Common Economy 可选：装了自动对接，扣费与发奖都走它的钱包；没装就用模组自带的内置钱包（新玩家初始 1000，管理员用 `/lottery give` 发币）。
3. 首次启动会自动生成 `config/luckydraw/lottery.json`，改完用 `/lottery reload` 生效，不用重启服务器。
4. `/lottery info` 可以查看当前价格、奖池数量、触发方块、经济来源和命令奖品身份。

## 已知问题

- 极少数插件会按玩家 UUID 单独查自己的权限表、不看命令来源，这类命令奖品仍可能失败；需要在那个插件里给玩家加对应权限节点，或给这条奖品加 `"commandAs": "console"`。
- 命令奖励没发出去时玩家会收到提示，服务器日志里搜 `[抽奖机] 奖品命令执行失败` 能看到命令原文和失败原因。
- 十连是抽 10 次，所以聊天栏会列 10 条结果，条数就是实际抽到的次数。
